# AI 师傅

AI 师傅课程制作专家，帮你制作课程、分析学习数据并生成学习报告。

## 类型

Agent 型（单专家）

## 功能

当前覆盖 AI 师傅课程制作的全流程：

- 拆解原始素材，规划课程结构
- 撰写符合平台规范的课程脚本
- 设计单选 / 多选 / 输入 / 分支等互动环节
- 配置变量与个性化学习路径
- 编排图片与多媒体内容
- 优化课程级提示词
- 审查和优化已有课程内容
- 部署、发布和管理课程，提供预览与后台链接
- 查询学习进度、订单收入和积分消耗，并解读分析结果
- 复盘单门课程的学习情况、课节健康度、学员参与和聚合画像，给出有证据的改进建议
- 使用平台学习数据或用户提供的报告数据，生成脱敏的 `course-learning-report.json` 和自包含、可打印的 `course-learning-report.html`

学习报告默认累计至当前，只分析单门课程；缺失数据会明确标注，不会当作零。订单收入和积分消耗仅在用户明确要求时加入报告附录，报告建议不会自动修改课程。

未来将扩展用户运营等能力。

## 技能

| 技能名 | 说明 |
| --- | --- |
| `ai-shifu-course-creator` | AI 师傅课程制作核心技能，按教学设计、MarkdownFlow 表达、CLI 操作三类提供能力，由智能体按任务自主组合 |
| `ai-shifu-learning-report` | 复用课程创作器的数据分析能力，为单门课程生成脱敏 JSON 和可打印 HTML 学习报告 |

## 使用示例

- 以「为什么要学习 AI」为主题做一个 AI 师傅课程，整体不超过 4 个小节，针对不同背景的用户进行个性化授课
- 帮我把这份上传的素材转成 AI 师傅课程
- 帮我查看我在 AI 师傅平台上有哪些课程
- 帮我分析一门 AI 师傅课程的学习情况，生成包含教学结论和改进建议的学习报告
